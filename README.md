# La Remise

Un catalogue pour partager et réserver des outils entre coopératives d'habitation.

## Utilisation

Ouvrir `index.html` dans un navigateur. Le catalogue est vide au départ : seuls les membres peuvent y ajouter leurs outils et réserver gratuitement. Un outil peut exiger une formation, que l'emprunteur doit confirmer avoir suivie. Toute personne peut envoyer une demande d'emprunt ou proposer une formation; les membres peuvent consulter et traiter ces propositions.

Les outils, réservations, demandes et propositions de formation sont enregistrés dans le stockage local du navigateur. Ils ne sont donc pas partagés entre les appareils et aucune notification n'est envoyée. Un serveur et une base de données sont nécessaires pour le partage réel entre coopératives.

## Accès membres

Aucun code ni compte n'est demandé. Les actions réservées aux membres reposent sur une simple confirmation d'adhésion. Comme le site est statique, cette confirmation ne vérifie pas réellement l'adhésion; une vérification fiable nécessite un serveur et une authentification.
